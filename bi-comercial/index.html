Introducción

Esta guía explica cómo configurar Claude Desktop para conversar en lenguaje natural con el informe de Power BI BI Comercial. Una vez completada, podrá hacer preguntas como «¿Cuál es el importe total de octubre por planta?» y obtener la respuesta directamente a partir del modelo de datos.

¿Cómo funciona? Claude se conecta al modelo del informe abierto en Power BI Desktop a través de un servidor MCP (Model Context Protocol) publicado por Microsoft. Claude interpreta la pregunta, la traduce a una consulta DAX, la ejecuta sobre el modelo y devuelve el resultado explicado.

Claude DesktopUsted escribe la pregunta y recibe la respuesta explicada.
Servidor MCPpowerbi-modeling-mcp.exe traduce la petición en consultas DAX.
Power BI DesktopEl archivo BI Comercial abierto en su equipo.

¿Quién hace cada parte?

Equipo técnico

Realiza la instalación y la configuración completa (pasos 1 a 9), en unos 15–20 minutos por equipo. Al terminar, deja creado y fijado en Claude el chat Agente BI Comercial.

Usuarios

Solo tienen que abrir ese chat y preguntar. Lo explica la sección Uso diario.

Requisitos previos

  • Equipo con Windows 10 u 11.
  • Power BI Desktop, gratuito en Microsoft Store. Si el equipo no lo tiene, se instala en el paso 6.
  • Acceso a Power BI Service con permiso para descargar el informe BI Comercial.
  • Una cuenta de Claude para iniciar sesión en Claude Desktop.
  • Un técnico con permisos para instalar aplicaciones en el equipo.

Instalación paso a paso

Equipo técnico
1

Paso 1

Instalar Claude Desktop

  1. Descargar la aplicación para Windows desde la web oficial de Claude.

  2. Ejecutar el instalador y seguir las instrucciones en pantalla.

  3. Abrir Claude Desktop e iniciar sesión con su cuenta.

claude.com/es/download
2

Paso 2

Instalar Visual Studio Code

Visual Studio Code se utiliza para instalar la extensión de Power BI (paso 3) y para editar el archivo de configuración de Claude (paso 5). Después no es necesario tenerlo abierto para usar Claude.

  1. Descargar Visual Studio Code desde su web oficial.

  2. Instalarlo con las opciones por defecto.

code.visualstudio.com
3

Paso 3

Instalar la extensión «Power BI Authoring MCP Server»

  1. Abrir Visual Studio Code.

  2. Abrir el panel de Extensiones (icono de bloques en la barra lateral izquierda o Ctrl + Mayús + X).

  3. Buscar Power BI Authoring MCP Server y comprobar que el editor es Microsoft (identificador analysis-services.powerbi-modeling-mcp).

  4. Pulsar Install.

4

Paso 4

Localizar la ruta del servidor MCP

La extensión incluye el ejecutable powerbi-modeling-mcp.exe, que es el que Claude utilizará para conectarse a Power BI. Necesitamos su ruta completa.

  1. Abrir el Explorador de archivos y pegar en la barra de direcciones:

    Barra de direcciones
    %USERPROFILE%\.vscode\extensions

  2. Entrar en la carpeta que empieza por analysis-services.powerbi-modeling-mcp- y, dentro, en la subcarpeta server.

  3. Hacer clic derecho sobre powerbi-modeling-mcp.exe → Copiar como ruta de acceso y guardarla en un bloc de notas, sin las comillas.

La ruta tendrá esta forma:

Estructura de carpetas
C:\Users\<SuUsuario>\.vscode\extensions\
└─ analysis-services.powerbi-modeling-mcp-<versión>-win32-<arquitectura>\
   └─ server\
      └─ powerbi-modeling-mcp.exe

Nota

<versión> (por ejemplo, 1.0.0) y <arquitectura> (x64 o arm64) dependen de cada equipo. Utilice siempre la ruta exacta que aparece en su Explorador de archivos.

5

Paso 5

Configurar Claude Desktop

Claude Desktop lee los servidores MCP de un archivo llamado claude_desktop_config.json. Su ubicación depende de cómo se haya instalado Claude. Pegue la primera ruta en la barra de direcciones del Explorador; si no existe, utilice la segunda.

Opción 1 · MSIX / Microsoft Store
%LOCALAPPDATA%\Packages\Claude_pzs8sxrjxfjjc\LocalCache\Roaming\Claude
Opción 2 · Instalador clásico (.exe)
%APPDATA%\Claude

Importante

En la versión MSIX, la opción Configuración → Desarrollador → Editar configuración de Claude Desktop puede abrir un archivo distinto del que la aplicación lee realmente. Recomendamos editar el archivo directamente en la carpeta indicada.

  1. Cerrar Claude Desktop por completo: además de cerrar la ventana, hacer clic derecho en su icono junto al reloj de Windows → Salir.

  2. Hacer una copia de seguridad del archivo (por ejemplo, claude_desktop_config.backup.json).

  3. Abrir el archivo con Visual Studio Code (clic derecho → Abrir con → Visual Studio Code).

  4. Añadir este bloque justo después de la primera llave { del archivo:

    Bloque a añadir · JSON
      "mcpServers": {
    "powerbi-modeling-mcp": {
      "command": "RUTA_DEL_PASO_4",
      "args": ["--start"]
    }
  },

  5. Sustituir RUTA_DEL_PASO_4 por la ruta copiada en el paso 4, duplicando cada barra invertida:

    Ejemplo de conversión
    Ruta copiada:  C:\Users\<SuUsuario>\.vscode\…\server\powerbi-modeling-mcp.exe
En el JSON:    C:\\Users\\<SuUsuario>\\.vscode\\…\\server\\powerbi-modeling-mcp.exe

  6. Guardar el archivo (Visual Studio Code subraya en rojo cualquier error de sintaxis) y volver a abrir Claude Desktop.

El archivo completo quedará con una estructura similar a esta. El resto del contenido que ya existía se mantiene sin cambios:

Resultado · claude_desktop_config.json
{
  "mcpServers": {
    "powerbi-modeling-mcp": {
      "command": "C:\\Users\\<SuUsuario>\\...\\server\\powerbi-modeling-mcp.exe",
      "args": ["--start"]
    }
  },
  "preferences": { ... }   ← configuración que ya existía
}

Reglas para que el archivo sea válido

  • Dentro del JSON, cada barra invertida \ de la ruta se escribe doble: \\.
  • La coma tras la llave de cierre de "mcpServers" es obligatoria si hay más contenido detrás.
  • Si el archivo ya contiene "mcpServers", no lo duplique: añada solo la entrada "powerbi-modeling-mcp" dentro del bloque existente.
  • Si el archivo está vacío o no existe, créelo con el bloque anterior envuelto entre { y }, sin la coma final.

Recomendado: modo solo lectura

Si el objetivo es únicamente consultar datos, sustituya la línea de argumentos por la siguiente. Así Claude podrá leer y analizar el modelo, pero no modificarlo.

Argumentos en modo solo lectura
"args": ["--start", "--readonly"]
6

Paso 6

Instalar Power BI Desktop

El informe se descarga como un archivo .pbix, que solo se puede abrir con Power BI Desktop. Si el equipo ya lo tiene instalado, pase al paso 7.

  1. Abrir Microsoft Store desde el menú Inicio y buscar Power BI Desktop. Comprobar que el editor es Microsoft.

  2. Pulsar Obtener (o Instalar) y esperar a que termine la instalación.

  3. Abrir Power BI Desktop una vez para comprobar que se inicia correctamente.

Power BI Desktop en Microsoft Store

¿Por qué desde Microsoft Store?

La versión de Microsoft Store se actualiza sola cada mes y no necesita permisos de administrador para instalarse.

7

Paso 7

Descargar y abrir el informe «BI Comercial»

El servidor MCP trabaja sobre el modelo abierto en Power BI Desktop, así que hace falta una copia local del informe.

  1. Acceder a Power BI Service (app.powerbi.com) y abrir el informe BI Comercial.

  2. Ir a Archivo → Descargar este archivo. Si se ofrece elegir, seleccionar la opción que incluye los datos (no la de conexión dinámica).

  3. Abrir el archivo .pbix descargado con Power BI Desktop y esperar a que termine de cargar.

Mantenga los datos al día

El archivo descargado es una fotografía de los datos en el momento de la descarga. La fecha de la última actualización aparece en la parte superior del informe en Power BI Service («Datos actualizados el …»). Cuando los datos se actualicen, repita este paso.

8

Paso 8

Conectar Claude al informe

  1. Con el informe abierto en Power BI Desktop, abrir Claude Desktop.

  2. Pulsar el botón + del cuadro de mensaje y entrar en Conectores.

  3. Comprobar que powerbi-modeling-mcp aparece activado.

  4. Entrar en Añadir desde powerbi-modeling-mcp y seleccionar ConnectToPowerBIDesktop.

  5. Cuando se solicite el nombre del informe, escribir el nombre del archivo abierto en Power BI Desktop y enviar el mensaje:

    Nombre del informe
    Proyeccion Comercial

  6. Claude confirmará la conexión. Haga una pregunta de prueba (por ejemplo, «¿Cuál es el importe total del último mes?») para comprobar que responde con datos.

Consejos

También puede conectarse escribiendo directamente en el chat:

Mensaje para Claude
Conéctate a "Proyeccion Comercial" en Power BI Desktop

La primera vez que Claude use una herramienta del servidor MCP pedirá permiso. Revise la acción y pulse Permitir.

9

Paso 9

Fijar el chat como «Agente BI Comercial»

Para que los usuarios no tengan que repetir la conexión, el equipo técnico deja preparado el chat del paso 8, ya iniciado y conectado al informe, con un nombre fijo y anclado en la barra lateral de Claude.

  1. En el chat del paso 8, abrir el menú de la conversación: clic en el título de la parte superior, o en ⋯ al pasar el ratón sobre la conversación en la barra lateral.

  2. Elegir Cambiar nombre y escribir:

    Nombre del chat
    Agente BI Comercial

  3. En el mismo menú, elegir Fijar. La conversación pasa a la sección de elementos fijados, en la parte superior de la barra lateral.

  4. Cerrar y volver a abrir Claude Desktop y comprobar que el chat Agente BI Comercial aparece fijado.

Hágalo con la cuenta del usuario

Los chats pertenecen a cada cuenta de Claude. Toda la configuración, y en especial los pasos 8 y 9, debe hacerse con la cuenta del usuario final iniciada en Claude Desktop, no con la del técnico.

Los nombres de las opciones del menú pueden variar ligeramente según la versión de Claude Desktop.

Uso diario

Usuarios

Con el equipo ya configurado, el día a día se reduce a tres pasos:

  1. Abrir el informe BI Comercial en Power BI Desktop. Si los datos se han actualizado en Power BI Service, descargar antes la nueva versión (paso 7).

  2. Abrir Claude Desktop y, en la barra lateral, entrar en el chat fijado Agente BI Comercial.

  3. Escribir la pregunta en lenguaje natural.

Si Claude no responde con datos

Al cerrar Power BI Desktop o reiniciar el equipo, la conexión se puede perder. Con el informe abierto, escriba en el mismo chat:

Mensaje para Claude
Conéctate a "Proyeccion Comercial" en Power BI Desktop

Ejemplos de preguntas

Desde el chat Agente BI Comercial puede preguntar en lenguaje natural. Estos ejemplos usan los campos del informe:

  • ¿Cuál es el importe total (Amount) de octubre de 2026 por planta?
  • Compara las toneladas (TotalTons) de Draxton Atxondo y Draxton Barcelona mes a mes en 2026.
  • ¿Cuáles son los 10 clientes con mayor importe en lo que va de año?
  • ¿Qué familias de producto han crecido más respecto al mes anterior?
  • Muéstrame la cantidad servida (QServida) por KAM y tipo de cliente en la perspectiva de Fundición.
  • ¿Cómo se calcula la medida Amount? Explícamelo de forma sencilla.

Para obtener mejores respuestas

Cuanto más concreta sea la pregunta (periodo, planta, cliente, perspectiva Consolidado / Fundición / Mecanizado), más precisa será la respuesta.

Buenas prácticas y seguridad

  • Trabaje siempre sobre la copia descargada. Los cambios en Power BI Desktop no afectan al informe publicado en Power BI Service. No vuelva a publicar el archivo desde Power BI Desktop.
  • Active el modo solo lectura (--readonly, paso 5) si solo va a consultar datos.
  • Verifique las cifras críticas contra el informe antes de usarlas en decisiones o comunicaciones formales.
  • Protección de datos: los resultados de las consultas se envían a Claude para generar la respuesta. Asegúrese de que su uso cumple la política de IA y de protección de datos de su organización.
  • Revise los permisos que solicita Claude antes de aceptarlos. Ante cualquier duda, deniegue la acción.

Solución de problemas

powerbi-modeling-mcp no aparece en Conectores

Causa probable
Claude no se reinició por completo, se editó un archivo de configuración distinto o el JSON tiene un error.
Solución
Salir de Claude desde el icono junto al reloj y volver a abrirlo. Comprobar la carpeta del paso 5 y revisar el JSON en Visual Studio Code.

El conector aparece, pero falla al iniciarse

Causa probable
Ruta del .exe incorrecta: barras simples en lugar de dobles, comillas sobrantes o una versión distinta.
Solución
Revisar la ruta del paso 4 y escribirla en el JSON con \\.

Dejó de funcionar tras una actualización

Causa probable
Visual Studio Code actualizó la extensión y la carpeta cambió de versión (por ejemplo, 1.0.0 → 1.0.1).
Solución
Repetir los pasos 4 y 5 con la nueva ruta. Opcional: desactivar Auto Update en la extensión.

El chat Agente BI Comercial responde sin datos o indica que no está conectado

Causa probable
Se cerró Power BI Desktop, se reabrió el informe o se reinició el equipo.
Solución
Con el informe abierto, escribir en el chat: Conéctate a "Proyeccion Comercial" en Power BI Desktop.

El chat fijado no aparece en la barra lateral

Causa probable
Se configuró con una cuenta de Claude distinta de la del usuario.
Solución
Iniciar sesión con la cuenta del usuario y repetir los pasos 8 y 9.

Claude avisa de que la conversación es demasiado larga

Causa probable
El chat ha acumulado muchas consultas.
Solución
Crear un chat nuevo repitiendo los pasos 8 y 9 y quitar el fijado del anterior.

Claude no encuentra el informe

Causa probable
Power BI Desktop no está abierto, el informe aún está cargando o el nombre no coincide.
Solución
Abrir el .pbix, esperar a que cargue y usar el nombre exacto del archivo.

El archivo .pbix descargado no se abre

Causa probable
Power BI Desktop no está instalado en el equipo.
Solución
Instalarlo desde Microsoft Store (paso 6) y volver a abrir el archivo.

Los datos no coinciden con Power BI Service

Causa probable
La copia local está desactualizada.
Solución
Volver a descargar el informe (paso 7).

Error de sintaxis al guardar el JSON

Causa probable
Falta o sobra una coma, o hay una llave sin cerrar.
Solución
Comparar con el ejemplo del paso 5 o restaurar la copia de seguridad.
